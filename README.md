# Forward deployed engineering

An Obsidian knowledge base about forward deployed engineering, Staff-level engineering practice and agentic development. Role guidance and general technical knowledge have separate syntheses and inventories. It brings together attributed sources, evolving syntheses, practical procedures and useful tools. Source claims, proposed practices and locally observed results are kept distinct.

Read the [published Markdown edition](https://github.com/alexbevi/forward-deployed-engineering/tree/published) for working links and generated catalogue tables on GitHub. It updates automatically from committed changes to `main`.
