# Playbooks

These procedures turn reading into practices an FDE can try. All initial playbooks are proposed; none has been validated through local use.

[Playbooks](Bases/Playbooks.md)

Use [Scope an engagement](Playbooks/Scope%20an%20engagement.md) before committing to work, [Build and review safely](Playbooks/Build%20and%20review%20safely.md) during implementation, [Evaluate outcomes and reuse](Playbooks/Evaluate%20outcomes%20and%20reuse.md) when reviewing value, [Prove a handover](Playbooks/Prove%20a%20handover.md) when transferring responsibility, and [Stage agent autonomy](Playbooks/Stage%20agent%20autonomy.md) when defining action scope.

For deployment acceptance, try [Rehearse a deployment from delivered artifacts](Playbooks/Rehearse%20a%20deployment%20from%20delivered%20artifacts.md). [Approaches](Approaches.md) explains the methods behind these procedures.

After trying a procedure, record the context, observed result, failure or limitation, and resulting revision in that playbook. A single trial is useful evidence but does not establish general effectiveness. Create a separate experiment note only when a substantial trial needs its own record.
