# Playbooks

These procedures turn reading into practices an FDE can try. All initial playbooks are proposed; none has been validated through local use.

![[Bases/Playbooks.base]]

Use [[Playbooks/Scope an engagement]] before committing to work, [[Playbooks/Build and review safely]] during implementation, [[Playbooks/Evaluate outcomes and reuse]] when reviewing value, [[Playbooks/Prove a handover]] when transferring responsibility, and [[Playbooks/Stage agent autonomy]] when defining action scope.

For deployment acceptance, try [[Playbooks/Rehearse a deployment from delivered artifacts]]. [[Approaches]] explains the methods behind these procedures.

After trying a procedure, record the context, observed result, failure or limitation, and resulting revision in that playbook. A single trial is useful evidence but does not establish general effectiveness. Create a separate experiment note only when a substantial trial needs its own record.
