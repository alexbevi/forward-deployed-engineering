# DGF-Bench repository

[Open the repository](https://github.com/jeremy1392/dgf-agentic-bench).

The repository linked by [2026-09-24 - Jeremy Canale - The Last Human Gate](../Articles/2026-09-24%20-%20Jeremy%20Canale%20-%20The%20Last%20Human%20Gate.md) publishes the paper sources, generated dossiers, benchmark code, original traces, repeated runs, deterministic control, evidence audits, cost records, and frozen-source references. The repository states that its concise and extended manuscripts share the same research and data; they are one evidence family, not independent confirmations.

Status is inspected, not reproduced. The repository structure and stated release contents were reviewed, but no code, result archive, checksum, or model run was executed locally. Use the frozen release identified by the paper rather than assuming the default branch reproduces the reported experiment.

See [Contract-based governed task transfer](../Approaches/Contract-based%20governed%20task%20transfer.md) for the proposed local adaptation. Return to [Resources](../Resources.md).
