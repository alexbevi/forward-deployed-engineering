# FDE Mission

[Open the browser exercise](https://pavanbelagatti.github.io/fde-playground/). It presents six decisions in the incident investigation scenario from [Belagatti's article](../Articles/2026-09-28%20-%20Pavan%20Belagatti%20-%20How%20to%20become%20a%20forward%20deployed%20engineer.md). Each answer gives immediate feedback and changes scores for customer trust, technical fit, and production readiness.

The score averages those three values. The final screen displays the same fictional 45-to-8-minute improvement regardless of the answers. The hosted page matched this [pinned copy of the implementation](https://github.com/pavanbelagatti/fde-playground/blob/443f11a7d90145ec325c5d20277b8276e630865c/index.html).

For a proposed peer exercise, explain the evidence behind each choice before revealing the feedback. At the rollout decision, ask what responders should see when a connector fails and what evidence would justify widening access. Use those answers for the debrief. The exercise has no recorded local use or evidence of learning outcomes.
