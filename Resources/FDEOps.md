## Useful FDE tasks

FDEOps provides 35 task skills and an `fde` coordinator for discovery, scope, architecture, implementation, verification and handover. Individual tasks can use supplied context without creating customer records. Its optional CLI maintains local Markdown engagement records and generates a fieldbook dashboard. These are documented capabilities, not locally demonstrated outcomes.

The inspected [scope method](https://github.com/suboss87/FDEOps/blob/e3e1469c73d54c49f43bac62c031b4e4a7f78cc8/skills/fde/references/hold-scope.md) distinguishes proposed changes from agreed scope. Its [handoff method](https://github.com/suboss87/FDEOps/blob/e3e1469c73d54c49f43bac62c031b4e4a7f78cc8/skills/fde/references/close.md) separates drafting an operating summary from demonstrating readiness to close. These offer concrete candidates for trying alongside [Scope an engagement](../Playbooks/Scope%20an%20engagement.md) and [Prove a handover](../Playbooks/Prove%20a%20handover.md).

## Setup and limits

The [installation guide](https://github.com/suboss87/FDEOps/blob/e3e1469c73d54c49f43bac62c031b4e4a7f78cc8/docs/install.md) offers individual skill installation, a coordinator and agent adapters. Installation uses Node.js and Git; the record CLI requires Node.js 18+. Host invocation and hooks differ, with session hooks oriented toward Claude Code. Compatibility in this workspace remains untested.

The [privacy documentation](https://github.com/suboss87/FDEOps/blob/e3e1469c73d54c49f43bac62c031b4e4a7f78cc8/PRIVACY.md) distinguishes local records from data the AI host may send to its provider. Masking covers selected patterns and does not intercept raw file reads or pasted text. Local storage alone does not establish that customer data stays local.

The project's [verification account](https://github.com/suboss87/FDEOps/blob/e3e1469c73d54c49f43bac62c031b4e4a7f78cc8/docs/verification.md) reports software checks and selected synthetic agent trials, while leaving customer outcomes and comparative benefit unproven. These reports share project provenance. No installation, model trial, CLI execution or test reproduction was performed for this catalogue review; status is `reviewed`.
