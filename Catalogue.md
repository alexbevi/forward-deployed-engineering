The source-family view groups overlapping material. Families are editorial provenance labels, not quality scores. A single family can contain disagreement or several evidence types. Use the missing-metadata view to find retrieval and verification gaps.

Continue to [Operating models](Operating%20models.md), [Playbooks](Playbooks.md), [People](People.md), and [Resources](Resources.md).

The downloaded-documents view links original PDFs and their Markdown search indices. Originals remain authoritative; indices can contain extraction errors and do not count as additional sources. Search this collection’s extracted text with `path:"Forward Deployed Engineering/Attachments" "governance"`.

The research-papers view exposes reviewed versions and derived approaches. Papers stay in the source inventory; reusable methods live in [Approaches](Approaches.md).
